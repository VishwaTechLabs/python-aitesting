## 🎯 Objective

Learn indentation, statements and readable Python structure.

## 📚 What You Will Learn

- **indentation**
- **comments**
- **statements**
- **expressions**
- **keywords**
- **identifiers**
- **PEP 8**

## 🔤 Syntax / Mental Model

```text
statement
    indented block
expression → value
```

## 💻 Example Map

1. Correct indentation
2. Write comments
3. Use meaningful identifiers
4. Fix a syntax error

## 🧪 Testing Connection

- Review a test script for readability
- Identify syntax vs logical failure

## 📝 Exercises

1. Complete the four examples.
2. Write 3 original examples.
3. Add one negative/edge case.
4. Explain the concept to another learner.

## 🔗 Official Resource

[Open official documentation](https://docs.python.org/3/)

> 💡 **Learning rule:** Don't just read the code. Predict the output → run it → change one value → observe the result → write a test.
