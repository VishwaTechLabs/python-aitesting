## 🎯 Objective

Understand names, values, assignment, dynamic typing and scope.

## 📚 What You Will Learn

- **assignment**
- **dynamic typing**
- **multiple assignment**
- **scope**
- **id()**
- **type()**

## 🔤 Syntax / Mental Model

```text
name = value
name → object/value
```

## 💻 Example Map

1. Assign a username
2. Swap two variables
3. Multiple assignment
4. Inspect type and id

## 🧪 Testing Connection

- Store expected/actual values separately
- Avoid unclear names in automation

## 📝 Exercises

1. Complete the four examples.
2. Write 3 original examples.
3. Add one negative/edge case.
4. Explain the concept to another learner.

## 🔗 Official Resource

[Open official documentation](https://docs.python.org/3/)

> 💡 **Learning rule:** Don't just read the code. Predict the output → run it → change one value → observe the result → write a test.
