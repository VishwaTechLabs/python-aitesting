## 🎯 Objective

Learn actual methods plus useful built-ins and operators for each type.

## 📚 What You Will Learn

- **string methods**
- **list methods**
- **tuple methods**
- **set methods**
- **dict methods**
- **numeric operations**
- **binary operations**

## 🔤 Syntax / Mental Model

```text
value.method(...)
built_in(value)
operator(value, value)
```

## 💻 Example Map

1. Clean a string
2. Sort test data
3. Merge dictionaries
4. Perform set comparisons

## 🧪 Testing Connection

- Use methods to prepare test data
- Validate transformed values

## 📝 Exercises

1. Complete the four examples.
2. Write 3 original examples.
3. Add one negative/edge case.
4. Explain the concept to another learner.

## 🔗 Official Resource

[Open official documentation](https://docs.python.org/3/)

> 💡 **Learning rule:** Don't just read the code. Predict the output → run it → change one value → observe the result → write a test.
