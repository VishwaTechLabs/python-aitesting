## 🎯 Objective

Understand reusable wrappers used by frameworks and test tooling.

## 📚 What You Will Learn

- **first-class functions**
- **nested functions**
- **closures**
- **decorators**
- **decorator arguments**

## 🔤 Syntax / Mental Model

```text
@decorator
def function():
    ...
```

## 💻 Example Map

1. Timing decorator
2. Logging decorator
3. Authorization wrapper
4. Closure retaining state

## 🧪 Testing Connection

- Create a retry decorator carefully
- Add metadata/logging around a test helper

## 📝 Exercises

1. Complete the four examples.
2. Write 3 original examples.
3. Add one negative/edge case.
4. Explain the concept to another learner.
