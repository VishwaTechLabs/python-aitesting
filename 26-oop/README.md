## 🎯 Objective

Apply encapsulation, inheritance, polymorphism and abstraction.

## 📚 What You Will Learn

- **encapsulation**
- **inheritance**
- **polymorphism**
- **abstraction**
- **abstract class**
- **composition**
- **aggregation**
- **super**

## 🔤 Syntax / Mental Model

```text
Base → derived
interface → implementation
object → composed objects
```

## 💻 Example Map

1. Base API client
2. Specialized page classes
3. Polymorphic validators
4. Composed test framework

## 🧪 Testing Connection

- Design a Page Object Model
- Avoid deep inheritance where composition is clearer

## 📝 Exercises

1. Complete the four examples.
2. Write 3 original examples.
3. Add one negative/edge case.
4. Explain the concept to another learner.

> 💡 **Learning rule:** Don't just read the code. Predict the output → run it → change one value → observe the result → write a test.
