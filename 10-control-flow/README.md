## 🎯 Objective

Control execution using conditions, loops and transfer statements.

## 📚 What You Will Learn

- **if**
- **if/else**
- **if/elif/else**
- **nested if**
- **for**
- **while**
- **range**
- **break**
- **continue**
- **pass**
- **return**
- **yield**

## 🔤 Syntax / Mental Model

```text
if condition:
    action

for item in collection:
    action
```

## 💻 Example Map

1. Validate a login
2. Loop through test cases
3. Stop on critical failure
4. Skip invalid test data

## 🧪 Testing Connection

- Create positive/negative branches
- Generate repeated test inputs

## 📝 Exercises

1. Complete the four examples.
2. Write 3 original examples.
3. Add one negative/edge case.
4. Explain the concept to another learner.

> 💡 **Learning rule:** Don't just read the code. Predict the output → run it → change one value → observe the result → write a test.
