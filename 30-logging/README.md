Create useful execution records for debugging automation.

## 📚 What You Will Learn

- **DEBUG**
- **INFO**
- **WARNING**
- **ERROR**
- **CRITICAL**
- **handlers**
- **formatters**
- **files**

## 🔤 Syntax / Mental Model

```text
logger.info('message')
logger.error('failure')
```

## 💻 Example Map

1. Console logging
2. File logging

## 🧪 Testing Connection
