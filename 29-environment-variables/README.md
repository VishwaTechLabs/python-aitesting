## 🎯 Objective

Handle runtime values and secrets without hard-coding credentials.

## 📚 What You Will Learn

- **os.environ**
- **os.getenv**
- **.env**
- **API keys**
- **tokens**
- **secret management**

## 🔤 Syntax / Mental Model

```text
process environment → os.getenv('NAME')
```

## 💻 Example Map

1. Read BASE_URL
2. Read timeout
3. Read a token
4. Validate required variable

## 🧪 Testing Connection

- Never print secrets
- Use CI secret stores for pipelines

## 📝 Exercises

1. Complete the four examples.
2. Write 3 original examples.
3. Add one negative/edge case.
4. Explain the concept to another learner.
