## 🎯 Objective

Read and write files used for test data, logs and artifacts.

## 📚 What You Will Learn

- **open**
- **read**
- **readline**
- **readlines**
- **write**
- **append**
- **with**
- **pathlib**

## 🔤 Syntax / Mental Model

```text
with open(path, mode) as file:
    data = file.read()
```

## 💻 Example Map

1. Read a text file
2. Write a test report
3. Append a log line
4. List files with pathlib

## 🧪 Testing Connection

- Load test data
- Verify an output artifact exists

## 📝 Exercises

1. Complete the four examples.
2. Write 3 original examples.
3. Add one negative/edge case.
4. Explain the concept to another learner.
