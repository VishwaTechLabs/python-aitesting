## 🎯 Objective

Split code into reusable Python files.

## 📚 What You Will Learn

- **import**
- **from import**
- **as**
- **custom modules**
- **__name__**
- **standard library**

## 🔤 Syntax / Mental Model

```text
module.py → import module
```

## 💻 Example Map

1. Create a math utility
2. Import a validator
3. Alias a module
4. Use __name__ guard

## 🧪 Testing Connection

- Separate test utilities from tests
- Avoid circular imports

## 📝 Exercises

1. Complete the four examples.
2. Write 3 original examples.
3. Add one negative/edge case.
4. Explain the concept to another learner.

## 🔗 Official Resource

[Open official documentation](https://docs.python.org/3/)

> 💡 **Learning rule:** Don't just read the code. Predict the output → run it → change one value → observe the result → write a test.
