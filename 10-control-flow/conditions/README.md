## 🎯 Objective

Control how a Python program chooses, repeats or exits execution.

## 📚 What You Will Learn

- **if**
- **if/else**
- **if/elif/else**
- **nested if**
- **multiple conditions**
- **conditional expression**

## 🔤 Syntax / Mental Model

```text
condition → branch
collection → loop
loop → break/continue
```

## 💻 Example Map

1. Login condition
2. Loop through test cases
3. Stop at a critical condition
4. Skip invalid data

## 🧪 Testing Connection

- Build positive/negative branches
- Use loops to execute repeated test data

## 📝 Exercises

1. Write examples for every topic.
2. Add nested logic.
3. Add a testing scenario.
4. Explain when each construct is appropriate.

## 🔗 Official Resource

[Open official documentation](https://docs.python.org/3/)

> 💡 **Learning rule:** Don't just read the code. Predict the output → run it → change one value → observe the result → write a test.
