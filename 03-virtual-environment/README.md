## 🎯 Objective

Isolate project dependencies so one project does not break another.

## 📚 What You Will Learn

- **venv**
- **activation**
- **deactivation**
- **pip**
- **requirements.txt**
- **dependency isolation**

## 🔤 Syntax / Mental Model

```text
python -m venv .venv → activate → pip install → pip freeze
```

## 💻 Example Map

1. Create a venv
2. Install requests
3. Freeze dependencies
4. Recreate from requirements.txt

## 🧪 Testing Connection

- Create an isolated test environment
- Explain why CI should install pinned dependencies

## 📝 Exercises

1. Complete the four examples.
2. Write 3 original examples.
3. Add one negative/edge case.
4. Explain the concept to another learner.
