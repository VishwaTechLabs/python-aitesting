## 🎯 Objective

Create and publish reusable Python packages.

## 📚 What You Will Learn

- **PyPI**
- **pyproject.toml**
- **metadata**
- **versioning**
- **build**
- **TestPyPI**
- **publishing**

## 🔤 Syntax / Mental Model

```text
source → build → distribution → repository → install
```

## 💻 Example Map

1. Create package structure
2. Write pyproject.toml
3. Build wheel/sdist
4. Publish to TestPyPI

## 🧪 Testing Connection

- Version a test utility package
- Validate installation in a clean venv

## 📝 Exercises

1. Complete the four examples.
2. Write 3 original examples.
3. Add one negative/edge case.
4. Explain the concept to another learner.

## 🔗 Official Resource

> 💡 **Learning rule:** Don't just read the code. Predict the output → run it → change one value → observe the result → write a test.
