# 06. Data Types 🧱

## 🗂️ Learning Classification

```text
DATA TYPES
├── BASIC / PRIMITIVE-STYLE
│   ├── Numeric → int, float, complex
│   ├── Boolean → bool
│   ├── Text → str
│   └── None → NoneType
│
└── NON-PRIMITIVE / COLLECTION & SPECIAL
    ├── Sequence → list, tuple, range
    ├── Set → set, frozenset
    ├── Mapping → dict
    └── Binary → bytes, bytearray, memoryview
```

> ℹ️ “Primitive/non-primitive” is a useful learning classification. Python's formal object/type model is more nuanced.

## 🎯 Key Question

**How do I choose the right type?**

- `int` → counts/status codes
- `float` → measurements/prices
- `str` → text/usernames/tokens
- `list` → ordered test cases
- `tuple` → fixed grouped values
- `set` → unique values
- `dict` → key-value/API data
- `bool` → true/false conditions
- `None` → absence of a value
