## 🎯 Objective

Process large or streaming data without loading everything into memory.

## 📚 What You Will Learn

- **yield**
- **generator function**
- **generator expression**
- **lazy evaluation**

## 🔤 Syntax / Mental Model

```text
def generate():
    yield value
```

## 💻 Example Map

1. Generate test IDs
2. Stream numbers
3. Generator expression
4. Stop iteration

## 🧪 Testing Connection

- Generate large test datasets lazily
- Avoid unnecessary memory use

## 📝 Exercises

1. Complete the four examples.
2. Write 3 original examples.
3. Add one negative/edge case.
4. Explain the concept to another learner.
