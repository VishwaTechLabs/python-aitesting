## 🎯 Objective

Handle failures predictably and create useful negative tests.

## 📚 What You Will Learn

- **SyntaxError**
- **ValueError**
- **TypeError**
- **KeyError**
- **IndexError**
- **FileNotFoundError**
- **try**
- **except**
- **else**
- **finally**
- **raise**

## 🔤 Syntax / Mental Model

```text
try:
    risky_operation()
except SpecificError:
    recover()
```

## 💻 Example Map

1. Handle invalid conversion
2. Handle missing file
3. Raise custom validation error
4. Use finally for cleanup

## 🧪 Testing Connection

- Turn expected exceptions into tests
- Never hide unexpected failures with broad except

## 📝 Exercises

1. Complete the four examples.
2. Write 3 original examples.
3. Add one negative/edge case.
4. Explain the concept to another learner.

## 🔗 Official Resource

[Open official documentation](https://docs.python.org/3/)

> 💡 **Learning rule:** Don't just read the code. Predict the output → run it → change one value → observe the result → write a test.
