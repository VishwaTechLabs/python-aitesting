## 🎯 Objective

Safely convert data received from users, APIs, CSV files and configuration.

## 📚 What You Will Learn

- **implicit conversion**
- **explicit conversion**
- **int()**
- **float()**
- **complex()**
- **bool()**
- **str()**
- **list()**
- **tuple()**
- **set()**
- **dict()**
- **type()**
- **isinstance()**

## 🔤 Syntax / Mental Model

```text
str('200') → int('200') → 200
'3.14' → float('3.14')
```

## 💻 Example Map

1. String to integer
2. String to float
3. List to set
4. Validate with isinstance()

## 🧪 Testing Connection

- Convert API status codes before assertions
- Handle invalid numeric input with ValueError

## 📝 Exercises

1. Complete the four examples.
2. Write 3 original examples.
3. Add one negative/edge case.
4. Explain the concept to another learner.
