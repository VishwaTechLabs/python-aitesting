## 🎯 Objective

Use lists, tuples, sets and dictionaries to model real test data.

## 📚 What You Will Learn

- **list**
- **tuple**
- **set**
- **dict**
- **indexing**
- **slicing**
- **packing**
- **unpacking**

## 🔤 Syntax / Mental Model

```text
collection[index]
collection[key]
for item in collection:
```

## 💻 Example Map

1. Store test cases in a list
2. Model an API response with dict
3. Remove duplicates with set
4. Unpack tuple data

## 🧪 Testing Connection

- Build a test-data matrix
- Validate required API keys

## 📝 Exercises

1. Complete the four examples.
2. Write 3 original examples.
3. Add one negative/edge case.
4. Explain the concept to another learner.
