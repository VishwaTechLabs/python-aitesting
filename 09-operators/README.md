## 🎯 Objective

Master arithmetic, comparison, assignment, logical, identity, membership and bitwise operators.

## 📚 What You Will Learn

- **arithmetic**
- **comparison**
- **assignment**
- **logical**
- **identity**
- **membership**
- **bitwise**

## 🔤 Syntax / Mental Model

```text
left operator right
```

## 💻 Example Map

1. Calculate totals
2. Compare status codes
3. Combine login conditions
4. Check membership

## 🧪 Testing Connection

- Build assertions from comparison operators
- Use logical operators for multi-condition validation

## 📝 Exercises

1. Complete the four examples.
2. Write 3 original examples.
3. Add one negative/edge case.
4. Explain the concept to another learner.
