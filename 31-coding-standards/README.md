## 🎯 Objective

Write clean, consistent and maintainable Python.

## 📚 What You Will Learn

- **PEP 8**
- **naming**
- **docstrings**
- **type hints**
- **DRY**
- **SOLID basics**
- **Ruff**
- **Flake8**
- **Pylint**

## 🔤 Syntax / Mental Model

```text
Readable code → review → lint → test → merge
```

## 💻 Example Map

1. Refactor a long function
2. Add type hints
3. Write a docstring
4. Fix lint findings

## 🧪 Testing Connection

- Review a test framework for maintainability
- Use linting in CI

## 📝 Exercises

1. Complete the four examples.
2. Write 3 original examples.
3. Add one negative/edge case.
4. Explain the concept to another learner.

## 🔗 Official Resource

[Open official documentation](https://docs.python.org/3/)

> 💡 **Learning rule:** Don't just read the code. Predict the output → run it → change one value → observe the result → write a test.
