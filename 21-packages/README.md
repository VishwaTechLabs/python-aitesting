## 🎯 Objective

Build maintainable package structures for automation frameworks.

## 📚 What You Will Learn

- **package**
- **__init__.py**
- **subpackage**
- **absolute import**
- **relative import**

## 🔤 Syntax / Mental Model

```text
package/
  __init__.py
  module.py
```

## 💻 Example Map

1. Create a utility package
2. Create subpackages
3. Import a helper
4. Expose a public function

## 🧪 Testing Connection

- Design a reusable automation package
- Keep package boundaries clear

## 📝 Exercises

1. Complete the four examples.
2. Write 3 original examples.
3. Add one negative/edge case.
4. Explain the concept to another learner.
