## 🎯 Objective

Build the mental model needed before writing Python.

## 📚 What You Will Learn

- **program**
- **algorithm**
- **flowchart**
- **pseudocode**
- **compiler**
- **interpreter**
- **runtime**
- **syntax**
- **logic**

## 🔤 Syntax / Mental Model

```text
Problem → Algorithm → Code → Execute → Output → Test
```

## 💻 Example Map

1. Calculate an average from three numbers
2. Convert a written problem into pseudocode
3. Draw a login flow
4. Compare compiler and interpreter

## 🧪 Testing Connection

- Turn a requirement into positive/negative test scenarios
- Identify expected vs actual result

## 📝 Exercises

1. Complete the four examples.
2. Write 3 original examples.
3. Add one negative/edge case.
4. Explain the concept to another learner.

## 🔗 Official Resource

[Open official documentation](https://docs.python.org/3/)

> 💡 **Learning rule:** Don't just read the code. Predict the output → run it → change one value → observe the result → write a test.
